# Ashu | Portfolio

A modern, animated single-page portfolio for Ashu, a BTech student.

- Plain HTML, CSS and JavaScript, no build step
- Three.js particle hero (loaded from cdnjs)
- Scroll-triggered animations, skill bars, counters, card tilt
- Placeholder images from picsum.photos
- Palette: `#7C5CFF`, `#22D3EE`, `#F472B6` on `#0B1020`

Open `index.html` in a browser, or serve the folder with any static host.
